# D&D Battle Table

Локальный боевой стол для D&D с онлайн-комнатами.

## Запуск

1. Открой терминал в этой папке.
2. Запусти:

```powershell
node server.js
```

3. Открой мастерскую комнату:

```text
http://localhost:5173/?room=main
```

Название комнаты можно менять прямо в ссылке: `?room=forest-ambush`, `?room=session-12`.

## Как позвать игроков

Если игроки в той же Wi-Fi/локальной сети, им нужна ссылка с IP твоего компьютера вместо `localhost`, например:

```text
http://192.168.1.25:5173/?room=main
```

Если игроки не в твоей сети, сайт нужно выложить на хостинг или открыть через туннель. Код уже готов к этому: сервер берёт порт из переменной `PORT`, а комнаты работают по URL.

## Важно

- Состояние комнаты сохраняется на сервере в папке `.rooms`.
- Картинки фигурок синхронизируются, потому что хранятся внутри сцены.
- Музыка по URL синхронизируется между игроками как ссылка.
- Локальный аудиофайл играет только у того, кто его добавил; для общей музыки лучше использовать прямую ссылку на MP3/OGG.
